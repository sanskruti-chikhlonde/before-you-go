# Before You Go

**Pack right. Go light.**

Before You Go is a simple trip packing assistant that helps users create a packing list based on their trip details.

## Features

- Enter destination and number of travel days
- Select weather conditions
- Choose activities for the trip
- Generate a customized packing list
- Add custom packing items
- Remove packing items
- Mark items as packed
- Track packing progress
- Reset the trip
- Light and dark mode
- Saves trip data using localStorage
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM
- Font Awesome
- localStorage

## How It Works

1. Enter your destination and trip duration.
2. Select the expected weather.
3. Choose your planned activities.
4. Click **Generate Packing List**.
5. Check items as you pack.
6. Add or remove items whenever needed.
